  - region "The work behind the interface.":
    - paragraph: 05 / Engineering decisions
    - heading "The work behind the interface." [level=2]
    - list:
      - generic: Integration
      - heading "Connect real components, then verify them" [level=3]
      - paragraph: Integrated Gemini structured generation, local Ollama embeddings and PostgreSQL/pgvector retrieval. Checked vector dimensions and model identity to avoid mixing incompatible embeddings.
      - generic: Retrieval evaluation
      - heading "Calibrate relevance and measure abstention" [level=3]
      - paragraph: Used separate calibration and frozen test questions to compare retrieval configurations. Selected a small threshold change and reported improved returned-evidence precision alongside reduced recall and false abstentions.
      - generic: Evidence contracts
      - heading "Make citations server-owned" [level=3]
      - paragraph: Introduced stable opaque passage IDs, Zod output validation and server-side source resolution. Unknown IDs and generated URLs cannot become trusted references. Exact claim/quote checks reject unsupported reference assertions.
      - generic: Orchestration
      - heading "Remove a redundant model inspection" [level=3]
      - paragraph: Reused server-prefetched context instead of an extra model-directed inspection. The trade-off is reduced exploratory freedom in exchange for fewer provider calls and potentially lower latency; one run does not prove a general latency gain.
      - generic: Safety precision
      - heading "Diagnose a caution mistaken for an instruction" [level=3]
      - paragraph: A blanket keyword check rejected a harmless structural-safety disclaimer. A narrow whole-warning correction preserved hazard keywords and checks across fields, with adversarial regressions for hidden instructions and ambiguous language.
      - generic: Reliability & persistence
      - heading "Separate execution success from answer quality" [level=3]
      - paragraph: Verified idempotent saves, owner isolation, deadlines and automated regressions. The final live run exposed unsupported structured certainty and missing geometry that passing schema and quotation checks did not catch.
